# OAuth client library attribution

AriAI uses **AppAuth-Android 0.11.1** by the OpenID Foundation and contributors (<https://github.com/openid/AppAuth-Android>) for browser-based OAuth 2.0 Authorization Code with PKCE, token exchange, and refresh-token handling. AppAuth-Android is distributed under the Apache License 2.0; the license text is included in [`apache-2.0.txt`](apache-2.0.txt).

AriAI uses AppAuth as a native public client and does not embed or store an OAuth client secret.
